# Sample Data Directory

This directory stores sample academic inputs used for development, testing, and demonstration of CoursePilot AI.

## Suggested Contents

- `syllabus_dsa_cs201.pdf`: Sample Data Structures and Algorithms university course syllabus.
- `lecture_notes/`: Sample PDF slides and markdown notes for RAG vector search verification.
- `eval_inputs/`: Benchmark questions and reference answers for retrieval accuracy evaluation.

> **Note**: Test files placed here should not contain proprietary or sensitive student data.
